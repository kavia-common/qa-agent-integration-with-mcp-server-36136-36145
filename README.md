# qa-agent-integration-with-mcp-server-36136-36145

This repository contains:
- q_and_a_backend: Django REST API providing Q&A and MCP integration endpoints.
- q_and_a_frontend: React app (Ocean Professional theme) to interact with the Q&A API.

Frontend quick start:
- cd q_and_a_frontend
- npm install
- cp .env.example .env (optionally set REACT_APP_API_BASE)
- npm start

- /docs
- /redoc
- /swagger.json
